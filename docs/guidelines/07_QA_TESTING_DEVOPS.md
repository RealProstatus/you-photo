## 2. Матрица обязательных проверок (`PyTest`)

Каждый тест должен проверять конкретный способ проверки из таблиц требований Функциональной спецификации:

1. **`U-C-01` / `US-08`**:
   - Регистрация с валидными данными и согласием создает роль `CLIENT`;
   - Без согласия на ПДн регистрация отклоняется (`3a`);
   - Пароль из 7 символов отклоняется (`5в`);
   - Занятый телефон или email отклоняется с предложением войти (`5б`).
2. **`U-C-02`**:
   - Вход как по телефону, так и по email открывает кабинет; неверный пароль не создает сессию.
3. **`U-C-03` / `S-INT-01`**:
   - Принимаются `JPEG`, `PNG`, `HEIC`, `TIFF` размером до `50 МБ` включительно (включая пограничный тест ровно `50 МБ`);
   - Отклоняются `BMP`, `PDF` и файл `51 МБ` с текстом на русском языке про формат или лимит 50 МБ; ранее загруженные файлы заказа не теряются.
4. **`U-C-04` / `U-C-06`**:
   - Заказ с двумя файлами разных форматов и тиражей рассчитывается как сумма позиций за `≤ 3 с`;
   - Размер больше максимальной области печати всех салонов блокирует подтверждение с пояснением.
5. **`U-C-05` / `U-A-02`**:
   - Скрытый салон (`is_active=False`) не отображается в списке пунктов выдачи и не получает новые заказы;
   - Удаление салона с активными заказами в работе блокируется.
6. **`US-02` / `U-A-05`**:
   - Автовыбор назначает салон с нужным исправным оборудованием, услугами и минимальной загрузкой/доставкой;
   - Если ни один салон не может выполнить заказ целиком — статус `PENDING_ROUTING` (`1a`);
   - Ручное переназначение администратором на салон без нужного оборудования/услуги отклоняется с причиной (`3a`).
7. **`U-M-01..04` / `S-SEC-03`**:
   - Менеджер салона `A` видит и скачивает файлы только заказов салона `A` и получает `403 Forbidden` при обращении к заказам или настройкам салона `B`;
   - Клиент получает `403 Forbidden` при обращении к очередям салонов и админским методам;
   - Недопустимый переход статуса (например, `COMPLETED` -> `NEW`) отклоняется с пояснением.
8. **`US-06` (Выдача)**:
   - Неверный код выдачи (`5a`) отклоняется, статус остается `READY_FOR_PICKUP`;
   - Верный код выдачи переводит заказ в `COMPLETED`;
   - Обнаружение брака при получении (`7a`) переводит заказ в `NEEDS_CLARIFICATION`.
9. **`US-07` / `U-M-05` / `U-M-06`**:
   - При подключенной камере снимок импортируется, кадрируется под стандарт документа, создается заказ без клиента сразу на текущий салон в статусе `PRINTING` и ставится в очередь принтера;
   - При отключенной камере (`3a`) выводится ошибка, заказ не создается;
   - При ошибке принтера (`8a`) статус остается `PRINTING`, доступен повтор печати.
10. **`S-SEC-04`**:
    - После сдвига времени на `30 суток + 1 час` от `completed_at` запуск `RetentionCleanupJob.purge_expired_photos()` удаляет исходный файл из хранилища, но карточка заказа и история статусов остаются в БД.
